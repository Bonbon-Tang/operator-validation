Operator Validation Framework

多后端 AI 加速器算子验证框架

NVIDIA H100 寒武纪 MLU590 FlagOS Triton

⚡ 快速开始

# 安装
pip install -e .

# 运行验证
python -m operator_validation.main --config configs/default.yaml

# 指定算子和规模
python -m operator_validation.main \
    --operators matmul softmax sdpa \
    --shapes small medium

🎯 核心特性

插件化后端 新增后端只需实现 BackendPlugin 接口
YAML 配置驱动 全部配置外部化，无需修改代码
ATen 算子映射 以 PyTorch ATen 接口为统一入口
精度 + 性能 MSE/相对误差/余弦相似度 + 延迟/吞吐

📁 仓库结构

operator_validation/
├── backend/           # 后端插件系统
│   ├── base.py        # BackendPlugin 抽象基类
│   ├── cuda_backend.py    # NVIDIA CUDA
│   ├── mlu_backend.py     # 寒武纪 MLU
│   └── triton_backend.py  # FlagOS Triton
├── engine/            # 核心验证引擎
│   ├── executor.py    # 算子执行器
│   ├── validator.py   # 验证调度
│   └── reporter.py    # 报告生成
└── configs/           # YAML 配置文件
